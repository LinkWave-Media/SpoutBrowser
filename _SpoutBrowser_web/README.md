# SpoutBrowser Web Content

This folder contains the source files hosted at https://bntre.github.io/SpoutBrowser/

The project includes two interactive web pages:

### 1. Splash Screen (`index.html`)
A lightweight, pure JavaScript page designed as the splash screen for **SpoutBrowser**
* Try it here: https://bntre.github.io/SpoutBrowser/

### 2. Demo (`demo.html`)
A 3D scene built with Three.js, for this demo video: https://www.youtube.com/watch?v=vOFj6aN5QR4.
* It uses the "Michelle" animated model by Mixamo, which is not included in this repo (but fetched at runtime from the official Three.js repository)
* Try it here: https://bntre.github.io/SpoutBrowser/demo.html
